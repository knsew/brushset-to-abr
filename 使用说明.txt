Brushset 转 ABR 使用说明（v3.1）
==============================

双击 PNGtoABR.exe 即可使用，不需要安装 Python 或其他环境。
这个程序只做一件事：把 Procreate 的 .brushset 笔刷包
转成一个 Photoshop 可以导入的 .abr 笔刷文件。

操作步骤
--------
1. 点击“添加笔刷包”，或直接把 .brushset 文件拖进窗口（Ctrl+O）。
2. 在右侧“输出设置”里点击“选择”，指定要保存的 .abr 位置。
3. 点击“转成 ABR”，或用快捷键 Ctrl+Enter。
4. 完成后点击“打开输出位置”，或勾选“完成后自动打开输出位置”。

每次只会生成一个 .abr 文件，不会生成资料夹，
也不会额外输出任何其他文件。

转换参数
--------
- 笔刷名字：自动读取每支笔刷在 Procreate 里的名字（支持中文）
- 笔刷间距：自动读取原始 spacing，不再使用全局默认值
- 笔尖图片：保留 Shape.png / Grain.png 的原始分辨率和 alpha
- ABR 版本：GUI 默认 2（带笔刷名，兼容性更好），可选 1（旧版）
- 反转 alpha：只有白底黑印的图片才需要勾选
- 自动裁剪透明边缘：默认开启
- RLE 压缩：默认开启，遇到兼容问题才勾“不压缩像素”

手动笔刷参数
------------
选中一支笔刷后，右侧“笔刷参数”可以手动调整：
- 间距 1-100%、尺寸 1-2500px、角度 0-360 度、圆度 1-100%。
- 调整实时作用于画布预览，也会写入本次 ABR 输出。
- 点“重置默认”恢复该笔刷的 Procreate 原始参数。

还原度报告
--------
选中一支笔刷后，右侧会显示 100 分制的还原度评分：
- 85 分以上：高保真；60-84 分：近似；60 分以下：受限。
- 笔尖形状、间距、角度、圆度、翻转可直接还原；
  湿边连续值、纹理合成、锥度预烘焙、动态曲线、散射、
  颜色动态等 Procreate 专属能力没有 ABR 等价字段，会扣分。

真实样本结论（蕾丝花边.brushset，130 支可转）：
- 像素级回读一致率 130/130（100%），参数核对 130/130。
- 可见保真平均 64.22/100：高保真 0 支、近似 95 支、受限 35 支。

预览
----
- 左侧列表会显示笔刷包缩略图、笔刷数量和大小。
- 点选笔刷包后，中间会显示每支笔刷的笔画预览。
- 画布顶部可切换背景：透明棋盘/白色/黑色；“颜色”按钮可改笔画颜色。
- 画布可缩放预览：工具栏 − / 百分比 / + / 适配，Ctrl+滚轮快速缩放，Ctrl+0 适配窗口，按住中键拖拽平移。
- 点任意预览图可以打开大图预览窗口，按 Esc 关闭。

快捷键
------
- Ctrl+O 添加笔刷包
- Ctrl+S 选择输出位置
- Ctrl+Enter 开始转换
- Delete 移除选中笔刷
- F1 关于

设置记忆
--------
程序会记住上次的输出位置、窗口位置和大小，
以及你调整过的所有转换设置，下次打开自动恢复。
设置保存在：
%APPDATA%\BrushsetToABR\settings.ini

如果转换失败，错误日志会写到：
%APPDATA%\BrushsetToABR\error.log
（一般用不到，出问题时可以把这个文件发给开发者。）

命令行
------
程序是 GUI 子系统，PowerShell 里请用 Start-Process -Wait。
- --cli 输出.abr 图片1.png [图片2.png ...]：图片转 ABR
- --convert-brushset 输出.abr 文件.brushset：笔刷包转 ABR
- --cli-extract 输出目录 文件.brushset|文件.abr：解包成 PNG
- --compare-pack 输出目录 文件.brushset：生成肉眼对照包
- --version 7：CLI 可写 ABR v6/v7；--invert/--no-crop/--no-rle 与界面选项对应

常见问题
--------
- 生成的 .abr 怎么导入 Photoshop？
  打开 Photoshop 的“画笔”面板 → 右上角菜单 → “导入画笔”，
  选择 ABR 即可。

- 一次可以放多个 .brushset 吗？
  可以，所有笔刷会合并到同一个 .abr 文件里。

- 什么时候要勾选“反转 alpha”？
  当笔刷图片是白底、黑色笔迹时勾选；正常透明底 PNG 不勾选。

- 为什么拖进去没有反应？
  请确认文件是真正的 .brushset 笔刷包，不是资料夹、
  .zip 压缩包或图片。
